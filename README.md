## 📖 Sobre

Este repositório foi criado para armazenar materiais de estudo da disciplina Técnicas de Programação, incluindo:
- Exercícios práticos
- Anotações de aula
- Trabalhos e projetos
- Exemplos de código

# 🚀 Como executar

Siga os passos abaixo para rodar os códigos localmente:

- Abra o VSCode
- Aperte nas teclas `Ctrl + Shift + '` ou clique em `Terminal + New Terminal`
- Digite `git clone https://github.com/mariasaldanhaa/tecnicas-de-programacao.git`
- Por fim, abra algum arquivo e aperte `F5` ou cique no botão ▶️ (Run) no canto superior direito
